│ 1. Data Preparation & Leakage Safeguards                                               │
│ • Cryptographic Hashing: Computes SHA-256 on raw fields (pre_text, post_text, table)   │
│   to programmatically guarantee 0% data leakage between train, val, and test splits.   │
│ • Gold + Noisy Padding: Extracts ground-truth table rows/sentences and injects random  │
│   distractors from the same page (up to k=5) to train model noise robustness.          │
│ • Chat Template Synchronization: Bakes model-native control tokens (e.g.,              │
│   <|start_header_id|>) directly into the training data to prevent formatting           │
│   divergence and attention drift during inference.                                     │

│ 2. Hybrid RAG Retriever (Context Construction)                                         │
│ • Header-Aware Table Chunking: Dynamically prepends column headers to every serialized │
│   table row chunk. This preserves the 2D visual layout for the LLM, preventing it      │
│   from losing the mapping between cell values and column metrics (e.g., years).        │
│ • Dual Search Strategy (50/50 Blending): Combines a BM25 sparse lexical matcher to     │
│   catch exact entity/date/currency strings, with a FAISS Dense index (all-MiniLM-L6-v2)│
│   to catch semantic financial synonyms, weighted equally via an Ensemble Retriever.    │

│ 3. Unified Inference Client Router                                                     │
│ • Deterministic Enforcer: Injects Greedy Decoding parameters (temperature=0.0 or       │
│   do_sample=False) into all payload requests. This forces the LLM to pick the highest  │
│   probability token, guaranteeing that mathematical outputs are strictly reproducible. │
│ • Real-time Telemetry: Hook-captures streaming payload chunks to measure Time to First │
│   Token (TTFT) and Tokens Per Second (TPS) dynamically without blocking generation.    │
│ • Dynamic Routing: Intercepts benchmark queries and routes them to the correct serving │
│   endpoint based on the target model evaluation identifier.                            │
